DATABASE CONSTRAINT LEVEL

Zero Duplicate Roll-Call Guaranteed

A database-level models.UniqueConstraint(fields=['session', 'student']) eliminates duplicate entries even under concurrent network submissions. The application layer handles upserts safely via update_or_create.

Verified in automated test test_duplicate_attendance_prevented_at_db_level.

class AttendanceRecord(models.Model):
    session = models.ForeignKey(AttendanceSession, ...)
    student = models.ForeignKey(StudentProfile, ...)
    status = models.CharField(max_length=10, choices=AttendanceStatus.choices)
    
    class Meta:
        constraints = [
            models.UniqueConstraint(
                fields=['session', 'student'],
                name='unique_attendance_per_session'
            )
        ]
PIPELINE AUTOMATION

Interactive Calculation & Certified Transcripts

Raw marks entered by faculty are validated ($0 \le \text{marks} \le \text{max\_marks}$). Percentages are computed and mapped automatically against the configured grading scale rules (A+, A, B, C, D, F) without manual teacher math.

Score: 92/100 → 92.0% → Grade A+ (4.0 GPA)
examinations/services.py • Automated Pipeline 
def calculate_grade(exam, percentage):
    rules = exam.grading_scale.rules.all()
    for rule in rules:
        if rule.min_percentage <= percentage <= rule.max_percentage:
            return rule.grade
    return "F"

def reconcile_ledger(self):
    total_paid = self.payments.aggregate(
        models.Sum('amount'))['amount__sum'] or Decimal('0.00')
    self.paid_amount = total_paid
    self.balance = self.total_amount - self.paid_amount
    if self.balance == Decimal('0.00'):
        self.status = InvoiceStatus.PAID
    self.save(update_fields=['paid_amount', 'balance', 'status'])
